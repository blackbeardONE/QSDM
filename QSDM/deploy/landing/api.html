Submitting transactions

Writes are signed on your device with ML-DSA-87 and posted as a signed envelope. The server never sees a private key.

POST /wallet/submit-signed

Submit a self-custody signed transaction. Get the next nonce from /wallet/nonce first; the web wallet and QSDM Hive build and sign this request for you.

Retired in v0.3.3: POST /api/v1/wallet/mint returns HTTP 410 Gone. Address-filtered transaction history, token and contract lists, and network topology require authentication and are not part of the public API.

Versioning

  • HTTP API: /api/v1, stableThe v1 in the URL is the API prefix, not a deprecation flag. There is no /api/v2. GET /versions lists what is served.
  • Mining protocol: v2 onlyIndependent of the HTTP version. /status reports mining.protocol_versions_accepted (live: —); v1 proofs are rejected.
The HTTP API contract is audited. Checklist rows pin URL stability, the wallet submit flow, replay protection, CORS and JWT posture. See audit.html?category=api.
