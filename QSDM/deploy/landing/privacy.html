QSDM DATA HANDLING

Privacy policy

How QSDM Hive, the QSDM Hive Wallet browser extension, and the reference services at qsdm.tech handle information.

Last updated: August 2, 2026

Scope Local data Browser extension Network features Retention Your controls Contact

Scope

This policy applies to the open-source QSDM Hive desktop application, the QSDM Hive Wallet browser extension, and the reference services operated at qsdm.tech.

A separately operated validator, task provider, Relay, website, or integration may have its own policy. Its operator controls the requests sent to that service.

Data kept on your computer

Hive stores account profiles, encrypted QSDM keystore files, settings, task state, logs, miner enrollment state, and optional Relay credentials in the operating system's application-data directories.

Wallet passphrases and private keys are intended to remain on your computer. QSDM does not hold them as account-recovery data. Losing both the keystore JSON and passphrase can permanently lose access to the wallet.

No advertising tracker. Hive analytics functions are disabled and do not transmit product-usage events.

QSDM Hive Wallet extension

The extension has one purpose: connect supported websites to the active QSDM wallet secured by QSDM Hive and route user-initiated wallet connection, balance, signing, and CELL transfer requests to Hive for explicit local approval.

Information it handles

  • the origin of the website requesting a wallet connection, which Chrome classifies as web history;
  • the public wallet address, which is an account identifier, and its balance;
  • an allowlisted wallet method and its parameters; and
  • the resulting approval, rejection, signature, or transaction response.

This structured data is exchanged with the QSDM Hive native messaging host on your computer. Site approvals and extension settings are stored locally until you revoke or clear them. The extension does not build or retain a general browsing history.

The provider loads automatically only on the official QSDM, QSDM Online, and Sky Fang HTTPS domains. On another HTTPS website, temporary page access is granted only after you explicitly open the extension for that tab. The store package does not request blanket host access.

Chrome Web Store disclosure categories

QSDM Hive Wallet declares Personally identifiable information (the public wallet address as an account identifier), Financial and payment information (wallet balance and transaction requests), and Web history (only the current website origin required for connection). It does not collect the other categories listed in the Chrome Web Store form.

Information it does not collect

  • the Hive PIN, wallet private keys, keystore JSON files, passphrases, or wallet recovery material;
  • page content, clicks, keystrokes, or general browsing history;
  • personal data for sale, personalized advertising, creditworthiness, or lending decisions; or
  • remote executable code. Extension logic is included in the submitted package.
Chrome Limited Use. QSDM Hive Wallet's use and transfer of information received from browser APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements. Browser data is used only to provide or improve the extension's single wallet-connection purpose.

Data sent for network features

Hive sends only the information needed for a feature you start or configure. Depending on the feature, this can include:

  • public wallet addresses and public keys;
  • signed transactions, task actions, proofs, and anti-replay values;
  • chain, balance, task, reward, and update requests;
  • miner enrollment identifiers, hardware capabilities, and mining proofs when mining is enabled;
  • bounded resource descriptions and signed workload receipts for Edge Agent, Relay, or Mother Hive participation; and
  • a public key, signature, and short-lived code when you explicitly link a supported integration.

Private wallet keys and passphrases must not be included in those requests. Optional external notification storage is contacted only when an operator configures the required credentials.

Retention and disclosure

Local data remains on your computer until you remove it, clear the relevant setting, or uninstall the software. Uninstalling Hive does not automatically destroy wallet backups or every application-data file because doing so could destroy access to funds.

Reference web and API infrastructure may retain ordinary security and operational logs, including source IP address, request time, endpoint, status, and rate-limit events. These logs are retained only as reasonably needed to operate, secure, and diagnose the services, subject to the infrastructure's configured retention.

QSDM does not sell personal information. Information is disclosed only as needed to provide a user-requested feature, to service providers operating the reference infrastructure, to comply with applicable law, or to protect users and the service from fraud, abuse, or security threats.

Public ledger transactions and accepted proofs are replicated records and generally cannot be deleted without invalidating the ledger.

Your controls

Mining, task execution, website connections, transaction approvals, and resource sharing are opt-in. You can reject a request, disconnect a website or Relay, stop tasks, clear extension data, close your Hive session, or uninstall the software.

Back up the QSDM keystore before intentionally deleting local application data. Never send wallet secrets in a support request.

Contact

Send privacy questions to ops@qsdm.tech. Do not include a private key, keystore file, passphrase, API token, recovery material, or approval code.
