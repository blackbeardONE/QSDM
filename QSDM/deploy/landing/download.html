Verify your download

Compute the SHA-256 of the file you downloaded and compare it with the value above or in the published checksum file. They must match exactly.

Windows (PowerShell)

Get-FileHash -Algorithm SHA256 .\qsdm-hive-1.4.21-win-x64.exe

Expected: b3f408f8…b48e6b (PowerShell prints it in upper case; case does not matter).

Linux (terminal)

sha256sum qsdm-hive-1.4.21-linux-x86_64.AppImage

Or check against the checksum file

sha256sum -c --ignore-missing qsdm-hive-1.4.21-linux-SHA256SUMS.txt

Release integrity

QSDM Hive for Windows is currently published without Microsoft Authenticode signing. The SignPath Foundation application was declined for now because QSDM needs more external public adoption signals before Foundation sponsorship is available.

Verify the SHA-256 checksum before installing. A checksum detects changed bytes; it does not make Windows show a verified publisher. SmartScreen may warn until QSDM has a paid or accepted Authenticode signing path.

QSDM also signs each release manifest and file hash with ML-DSA-87. This check is separate from Microsoft Authenticode. Current Windows builds are unsigned. Trust the release only after the versioned download URL, SHA-256 checksum, and QSDM-native release signature match the public manifest.
