SUPPORT

Get the right kind of help.

Use public support for ordinary defects and a private channel for security issues. Never share wallet recovery material.

Product support

For Hive, extension, account, validator, or documentation problems, search the documentation first. If the issue remains, open a GitHub issue with the affected version, operating system, expected result, and redacted logs.

TroubleshootingGitHub issues

Account and privacy requests

Email ops@qsdm.tech for QSDM Account access or deletion requests and general website support. Send the request from the verified account email when possible.

Security vulnerabilities

Use GitHub's private vulnerability-reporting page. Do not open a public issue with exploit details, credentials, private keys, wallet backups, or personal information.

Report privatelySecurity policy

What support will never ask for

  • wallet private keys or recovery phrases;
  • keystore JSON files or passphrases;
  • remote desktop access to move funds; or
  • payment to unlock an account or wallet.
