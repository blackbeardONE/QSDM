QSDM HIVE WALLET EXTENSION

Wallet connection support

Help for connecting supported websites to the wallet secured by QSDM Hive. The extension never stores your keystore JSON, passphrase, or private key.

Download QSDM Hive Read the Hive guide Email support

Start here

The extension is a bridge to Hive, not a separate wallet. Hive must be installed, running, and unlocked before a website can connect.

01

Open Hive

Install the latest QSDM Hive release and open or import your QSDM wallet.

02

Open the website

Visit a supported HTTPS website and select its QSDM wallet connection command.

03

Approve locally

Open the extension, connect the current site, and approve the request in Hive.

Common fixes

Use these checks before reinstalling either component.

Hive is not running
Start or restart QSDM Hive and wait until the wallet status is ready. Then reopen the extension popup.
Site is not connected
Open the website first, select the extension, and choose Connect This Site. Complete the approval window in Hive.
Approval did not appear
Bring Hive to the foreground and check for a pending wallet request. Signing and CELL transfers always require a separate approval.
Connection stopped after an update
Update Hive and the extension to their current releases, restart the browser, and reconnect the website. Store and development builds use different trusted extension identities.
Wrong website shown
Make the intended HTTPS tab active before opening the extension. Local development is allowed only on localhost or 127.0.0.1.

General support

Describe the browser, operating system, Hive version, extension version, and the visible error. Never attach wallet secrets.
